# Security Policy

LR-Tablet is a local-first study application that stores learning progress, imported exercises, annotations and backups on the user's device.

Please privately report:

- unsafe import parsing;
- local data exposure;
- backup integrity bypass;
- unintended network transmission;
- Android/Web build or dependency issues that materially affect user data.

Do not attach copyrighted exam material, personal data, account credentials, or private backups to public issues.
