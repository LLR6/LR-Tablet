# Roadmap

## Current foundation

- Tablet-first reading workflow
- Local progress / timing / annotations
- Built-in and imported exercises
- Question-bank integrity validation
- Cloud package manifest validation
- Versioned SHA-256 backup envelope
- Android CI build on main

## Next

- schema version migration tests;
- import-preview validation before saving;
- per-question source metadata;
- stronger backup migration coverage;
- offline search over notes and wrong answers.

## Later

- spaced review scheduling;
- richer local analytics;
- optional encrypted local backup export;
- package-diff view before question-bank update.

## Non-goals

- silently uploading study data;
- accepting malformed question packages;
- tying core study flow to an online service.
